# Cavaleiros do Zodíaco – Carrossel de Personagens (Atualizado)

Carrossel interativo com personagens dos Cavaleiros do Zodíaco.

## O que mudou nesta versão

- Layout dividido: **texto à esquerda** + **imagem à direita**
- Fundo preto limpo
- Imagens com `object-fit: cover` (não esticam mais)
- Navegação com **bolinhas + setas**
- Navegação pelo **teclado** (← →)
- **Autoplay** (muda a cada 6 segundos)
- Pausa automática quando o mouse está em cima
- Nome + constelação de cada personagem
- Transições suaves
- Responsivo (mobile-friendly)

## Tecnologias
- HTML5, CSS3, JavaScript

## Como visualizar
Abra o arquivo `index.html` no navegador.
